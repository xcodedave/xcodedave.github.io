# N64 button icons: attribution

These SVGs are the N64 controller button icons from SmashWiki
(https://www.ssbwiki.com/Category:Button_icons_(N64)), used by the on-screen touch controls
(`crates/sm64-web/src/touch_web.rs`). They are not derived from any ROM.

- Author: Toomai Glittershine (wiki user [Toomai](https://www.ssbwiki.com/User:Toomai), uploader of
  every file below; the SVG headers read "Created with Inkscape by Toomai Glittershine for SmashWiki").
- License: [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)
  as stated on each file page.
- The files here are **unmodified** downloads of the original uploads (no recolouring or cropping).
  Any modified version of these icons added to this folder is also CC BY-SA 4.0 (ShareAlike) and
  must be kept as a separate file and listed here.
- The page links to `credits.html` (this folder) from a small "icons: SSBWiki, CC BY-SA 4.0" credit
  in the bottom-right corner.
